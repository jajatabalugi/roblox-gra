# Wolf Street Tycoon

[Pobierz plik gry do Roblox Studio](https://github.com/jajatabalugi/roblox-gra/raw/c13380acb5f1f910a8a945382dcfbf054bc014ef/Wolf-Street-Tycoon.rbxlx)

1. Zapisz plik `Wolf-Street-Tycoon.rbxlx` na komputerze.
2. Otwórz Roblox Studio → File → Open from File i wybierz ten plik.
3. Naciśnij Play / F5. Jeśli miałeś otwartą starszą kopię gry, najpierw zatrzymaj Play i otwórz nowo pobrany plik.

Prototyp zawiera sześć biur, 18 ulepszeń, trzy piętra, kontrakty z serią, automatyczny dochód, zadania, wydarzenia rynkowe oraz prestiż. Wszystkie skrypty są osadzone w pliku gry i można je edytować w Explorerze Studio.

Sterowanie: WASD, spacja, F — kontrakt, B — zakup, H — biuro; interakcje w świecie przez podpowiedzi. Dostępne są przyciski dotykowe.

Zapis wymaga opublikowanej gry. W Studio bez dostępu do DataStore działa tryb testowy bez trwałego zapisu. Do testów zapisu w opublikowanej kopii testowej włącz Game Settings → Security → Enable Studio Access to API Services.

Testy logiki ekonomii, zapisu, świata, serwera i interfejsu przeszły w środowisku z atrapami API. Pełne działanie silnika, wygląd i fizykę należy sprawdzić w Roblox Studio przed publiczną publikacją.

Poprawka odrodzenia: stała podłoga i neutralny spawn poza generowaną mapą, zachowanie poprzedniej mapy do ukończenia budowy nowej oraz ładowanie postaci dopiero po przygotowaniu biura. Kolejność spawnu i resetu sprawdzono w 37 testach z atrapami usług; pełny test silnika nadal wymaga Roblox Studio.
